## Independent review after round 4

A separate reviewer, who had not seen the work, checked everything the loop added (`railway-catalog..sota-improvements`) and reproduced each finding before reporting it. All fixed in `a9cf220`, each with a regression test that fails against the pre-fix code:

- **Fence escape (medium).** Only exact lowercase `</tag>` was neutralized. Now every open or close form, in any case or spacing, is neutralized in both model inputs.
- **OTLP credential in argv (medium).** Headers now go through a 0600 file (`curl -H @file`), parsed per the OTel spec (whitespace trimmed, values percent-decoded). Ambient `OTEL_*` variables from the shell are ignored.
- **Unrecoverable near-duplicate drops (medium).** Dropped pages are now kept in `private/near-dups/<run>`.
- **One malformed writer page aborted the run (low-medium).** A bad page is now dropped alone. On a duplicate slug the first page wins everywhere: HTML, manifest and ledger.
- **Tool isolation depended on optional flags (low).** `--strict-mcp-config`, `--tools`, `--json-schema` and `--system-prompt` are now required; a CLI without them fails closed before any model call.
- **Tests (low).** Removed a vacuous assertion. The eval's validator loop now fails if the validator itself can't run.

| 10 | **Resilient model calls.** Classify failures: transient (overloaded, 429/5xx, timeout) gets a bounded retry with jittered backoff. | 12 | **Validator fuzzing.** Run a corpus of the OWASP XSS filter-evasion vectors, plus generated mutations (case, entity encoding, null bytes, attribute splitting), through the page validator and post-scan. In the oracle a case counts as active if script runs, any network request is made or the page navigates, after every element is hovered, focused and clicked. **What it found:** the blocklist validator on its own let 128 of 1,406 through, and the oracle confirmed real bypasses: a tab/newline/form-feed between the tag name and an attribute (`<a\thref=javascript:…>`, `<iframe\nsrc=…>`), CSS escapes and comments (`\75rl(`, `u/**/rl(`), unquoted entity-split schemes, and `meta http-equiv` hidden behind a quoted `>`. **Fixed two ways:** (1) a new **markup allowlist** as the primary control (bare `h2/h3/p/ul/ol/li/pre/code/strong/em/table…` tags only, no attributes, every other tag-opening `<` must be escaped) blocks **1,406/1,406**; (2) the blocklist now tokenizes attributes like a browser, decodes CSS escapes and comments, and normalizes URLs per value. On its own it blocks **1,404/1,406**, and the 2 remaining cases are proven inert in Chromium and pinned in `inert-allowlist.txt`. The real golden pages pass both layers unchanged. CI runs the fuzz without a browser (19s): any new passer that isn't on the allowlist fails | **done** (loop 2, round 3) |
| 13 | **Per-run canary.** Plant a synthetic, unique secret-shaped canary in the bundle before the scrub. Assert it never appears in the model input, the pages or the telemetry.
