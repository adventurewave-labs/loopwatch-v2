What it does

Private by construction

Allowlist first: an empty INCLUDE_PROJECTS reads nothing, GitHub included. Secrets are scrubbed before any model sees text, pages are re-scanned after, and the validator drops anything with scripts, handlers or external loads.

Two-stage cost floor

Haiku triages everything; sonnet runs only on cited excerpts when candidates exist. Runs stop before any call on quiet days, and BUDGET_USD / MAX_BUNDLE_KB / a monthly cap fail closed.

You are the publisher

Nothing ships itself. Every run becomes a branch and a PR you merge; closing a PR discards it forever. The catalog serves behind Basic Auth that fails closed — 503 until credentials exist.

Privacy is enforced, not advised

allowlist
only INCLUDE_PROJECTS is read; excludes win; the catalog repo is never re-read
scrub → model
sk- keys, GitHub/AWS/Stripe tokens, JWTs, PEM, bearer, connection strings, emails — plus your redact.list
model → scan
pages, titles, summaries and tags re-scanned with the same rules; any hit drops the page
--tools ""
neither model call gets a tool; it sees only the stdin loopwatch puts there, fenced as data
firewall
validator drops script/on*/iframe/embed/form/meta-http-equiv, external and javascript: URLs, CSS url()
fail closed
catalog 503s until CATALOG_USER/PASSWORD exist; publishing refuses unless SITE_VISIBILITY=protected

Byte-offset watermarks stop at the last newline, carry a first-bytes fingerprint, and are property-tested for exactly-once delivery across append, truncate, rotate and failed-run sequences.

The pipeline

COLLECT

Allowlisted Claude Code / Cowork transcripts + GitHub commits and merged PRs. Byte watermarks, bundle cap, oldest trimmed first.

SCRUB

Built-in secret patterns + your gitignored redact.list, case-insensitive, applied to every line before anything leaves the machine.

TRIAGE

Stage A — haiku, read-only, tool-free: digest + 0..5 candidates with line-range evidence. Zero candidates → stop, no Stage B.

WRITE

Stage B — sonnet sees only the cited excerpts, schema-constrained. Page HTML is rendered by loopwatch, never by the model.

VALIDATE

Page firewall + post-scan for secrets and redact.list hits. Drops are counted in the ledger without the matched text.

PUBLISH

A loopwatch/<date>-<time> branch and a PR — one open PR at a time, closed PRs never re-proposed. Railway serves main behind auth.

Commands

loopwatch runcollect → triage → write → validate → PR. --export-md DIR for Markdown
loopwatch dry-runthe same, without publishing — the run dir is kept for inspection
loopwatch sourcesevery candidate source with include / skip:self / skip:not-allowlisted
loopwatch preflightPASS/WARN/FAIL privacy + visibility checks; exits non-zero on any FAIL
loopwatch ledger [N]last N runs, totals, median cost of runs that made model calls
loopwatch doctorone OK/WARN/FAIL line each: config, redact mode, deps, last run, privacy self-test, monthly spend, anomalies, prompt drift. Exits 1 on FAIL — cron-gateable
loopwatch schedule install 21 30opt-in nightly launchd job; remove undoes it

Install (Mac)

gh repo clone adventurewave-labs/loopwatch-v2 ~/.local/share/loopwatch
~/.local/share/loopwatch/bin/install.sh
$EDITOR ~/.config/loopwatch/loopwatch.conf   # INCLUDE_PROJECTS: empty means nothing is collected
loopwatch sources && loopwatch preflight     # what would be read, and why
loopwatch dry-run                            # the whole pipeline, nothing published

Needs bash (stock 3.2 is fine), jq, git, an authenticated gh, and the claude CLI. Installs no schedule. From a session, just ask: "run loopwatch".

Measured, not estimated

Structured mode on claude 2.1.283, same sample day, dry runs: a 3-page day cost $0.158 in 69s ($0.057 haiku + $0.101 sonnet). The earlier agentic mode produced 1 page for $0.376 — about 83% less per page. Each call has a fixed floor of ~$0.013–0.018.
